# TMS9918B Design Notes

Why the TMS9918B is the way it is: the 1983 setting, the two designs (TMS9918+ and TMS9918B), why the dynamic RAM
decides the whole architecture, features and their precedents, rejected alternatives, cost, verification and the
open specification.

| File | Edition |
|---|---|
| `TMS9918B_Design_Notes.pdf` | 13 pages, same layout as the Data Manual |
| `TMS9918B_Design_Notes.md` | Markdown edition with linked contents |

Rebuild both editions: `python3 source/build_notes.py TMS9918B_Design_Notes.pdf` (ReportLab 4).
