## 80 versus 64 columns

80 columns of 6x8 characters (12 units each) need, every 4 columns, one 4-byte name cycle (22 units) and 4 pattern bytes (4 x 7 units): 50 units in 48. Pattern bytes of different characters are not adjacent, so no burst can merge them: 80 columns are not available. 64 columns of 8x8 characters (16 units each) give 64 units per group: 50 units of reads plus two CPU cycles (Text64).
